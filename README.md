# Gourisha Rathore — Professional Portfolio

A modern, fast-loading portfolio showcasing skills, projects, and contact information.

## Live Demo
🌐 **https://gourisharathore.github.io**

## Features
- ✨ Dynamic water ripple background (Canvas 2D API)
- ⌨️ Animated typing effect with rotating titles
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎨 Glass-morphism effects and smooth animations
- 📥 Resume download integration
- 🔗 Smooth scroll navigation
- ⚡ Fast loading (no frameworks, pure vanilla JS)

## Tech Stack
- **HTML5** — Semantic structure
- **CSS3** — Animations, Grid, Flexbox, responsive design
- **Vanilla JavaScript** — Canvas ripple, typing animation, scroll-triggered entrances
- **Font Awesome 6.4** — Icons via CDN

## File Structure
```
├── index.html          # Main page structure
├── styles.css          # All styling and animations
├── script.js           # Ripple effect, typing, interactions
├── .nojekyll           # GitHub Pages configuration
├── logo.png            # Navbar logo
├── profile.jpg         # Hero section photo
├── about.png           # About section photo
└── resume.pdf          # Resume file
```

## Quick Start (Local)
1. Open `index.html` in your browser
2. No server needed — works instantly

Or run a local server:
```powershell
npx http-server -p 8000
```
Then visit `http://127.0.0.1:8000`

## Deployment (GitHub Pages)
Already live at: **https://gourisharathore.github.io**

### To Update:
1. Edit files locally (`index.html`, `styles.css`, `script.js`)
2. Push changes to GitHub repo
3. Changes live in ~2 minutes

### File Naming (Important)
Keep asset names exactly as shown:
- Navbar logo: `logo.png`
- Hero photo: `profile.jpg`
- About photo: `about.png`
- Resume: `resume.pdf`

## Customization
- **Change text**: Edit content in `index.html`
- **Change colors**: Update CSS variables in `styles.css`
- **Replace images**: Upload new files with same names
- **Update resume**: Replace `resume.pdf`
